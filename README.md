# Crypto PnL Calculator

A simple and fast cryptocurrency profit & loss calculator.

## 🚀 Live Demo

[Open Crypto PnL Calculator](https://nikatose.github.io/crypto-pnl-calculator/)

## ✨ Features

- Calculate crypto profit and loss
- Calculate ROI
- Include trading fees
- Responsive design
- No backend required
- Runs entirely in the browser
- No data collection

## 📊 How It Works

Enter:

1. Buy price
2. Sell price
3. Amount of cryptocurrency
4. Trading fee

The calculator automatically estimates your:

- Investment
- Profit or Loss
- ROI

- HTML
- CSS
- JavaScript
